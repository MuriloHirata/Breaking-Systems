# 🎮 Breaking Systems

A 2D pixel-art game developed as a college project at **Fatec Campinas**.

Breaking Systems is a game inspired by the world of computing, where the player controls a USB flash drive fighting through different stages inside a fictional computer system.

## 🎮 Play Online

**[▶️ Play Breaking Systems](https://murilohirata.github.io/Breaking-Systems/)**

The game runs directly in the browser using HTML, CSS and JavaScript.

Additional controls and settings are available in the game.

## 🗺️ Game

The game contains three stages, each representing a different part of a fictional computer environment.

- **Stage 1** — File extraction
- **Stage 2** — Operating system security
- **Stage 3** — BIOS and final system challenge

The game features enemies, projectiles, platforming, combat, sound effects and a final boss encounter.

## 📚 Academic Context

Breaking Systems was developed as a project for **Fatec Campinas – Análise e Desenvolvimento de Sistemas** and presented in the context of **Fatec Portas Abertas**.

The project was created as an opportunity to practice:

- JavaScript game development
- HTML/CSS
- Game logic and state management
- Collision detection
- Object-oriented programming concepts
- Asset organization
- Git and GitHub
- Web deployment
